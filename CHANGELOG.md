# Changelog

All notable changes to the Gemma Medical Scribe project will be documented in this file.

## [1.0.0] - 2024-03-05

### Added
- Initial release of Gemma Medical Scribe
- Streamlit web interface for clinical note generation
- SOAP note formatting with Gemma 4 E4B model
- OCR chart scanning via Tesseract
- Offline medical dictionary lookup agent
- Docker deployment support
- Unit tests for core utilities

## [0.5.0] - 2024-02-20

### Added
- Docker and Docker Compose configuration
- Environment variable configuration support
- Setup.py for package distribution

## [0.3.0] - 2024-01-09

### Added
- Configuration module with model settings
- Utility functions for text processing and medical term extraction
- Input sanitization and patient ID validation

## [0.1.0] - 2023-10-03

### Added
- Initial project structure
- .gitignore for Python projects
- Basic Streamlit app with manual notes input
- Scribe agent with medical dictionary lookup
